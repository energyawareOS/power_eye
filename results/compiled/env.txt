cpu_model: Intel(R) Xeon(R) CPU E5-2650 v4 @ 2.20GHz, 2 sockets, 24 CPUs, SMT off
kernel: 6.8.0-149-generic (Ubuntu), same server for all rows in results.csv
bios_cstate_settings: package C-state limit C6 (retention), C6 on, C1E on, turbo off.
  OS: all cpuidle states enabled, menu governor, intel_pstate active/powersave.
  (BIOS options are not readable from the OS; this was recorded by hand.)

## Where each condition comes from (column `source` = <results dir>/<scenario>)

none      dose-pkgc6/none (8 runs, 120 s windows, settle 20 s)
          sysfs-vs-bpf/none (6 runs, 60 s windows, settle 10 s)
fixed     power_eye sysfs, -i 1 / 0.2 / 0.05 / 0.01 (dose-pkgc6, 8 runs each, 120 s)
          and 0.05 / 0.01 with -d (sysfs-vs-bpf, 6 runs each, 60 s).
          Requested 0.1 s and 10 s were NOT measured; 0.05 and 0.2 bracket 0.1.
ebpf      power_eye -B -d at -i 0.05 and -i 0.01 (sysfs-vs-bpf/bpf20, bpf100,
          6 runs each, 60 s). interval_s is left empty per the spec, the rate
          is only in `source`. At these rates -B forces samples (stale limit =
          interval/2), so it is close to sysfs, not the idle-piggyback regime.
          Not measured: -B at -i 1.
adaptive  NOT a bench run. One continuous server run (-B -d -i 1 -A 600 -C 0.5
          -F 25, 2026-11-25 17:35-19:05). One row per 10-minute coma window
          (run = window number): pkg power and deep % are the window values
          printed by the tool; tool_idle_exits is estimated from the OBS-WAKE
          column (rate x tick length, at least 1 wake per tick) / window time.
          wakeups_per_s is empty (system-wide idle entries were not measured).
          Window 1 includes the interval ramp-up and window 2 is busy (another
          job); windows 6-8 are the long-interval steady state. No `none`
          baseline was taken in that session.
node_exporter  NOT in results.csv. Only smoke2 exists (15 s scrape, 2 runs,
          30 s windows, kernel 6.8.0-134, BIOS pkg C-state limit auto, so pkg
          C6 = 0 % and ~45 W instead of ~25 W). Kept in
          results_node_exporter_old_bios.csv with its own none and pe1s rows.

## Columns

pkg_power_w            RAPL energy-pkg over the window / window time (W)
deep_cstate_pct        package C6 + C7 residency (%)
wakeups_per_s          system-wide idle entries per second (cpuidle usage diff)
tool_idle_exits_per_s  observer voluntary context switches per second; does
                       not include CPUs woken by IPI for sysfs RAPL reads.
                       Empty for none.
source                 extra column (not in the requested list); drop it if
                       the strict 7-column form is needed

## Caveats

- Rows of different sources were measured in different sessions (11-25 12:39 and
  16:20, adaptive 17:35); compare within a source (against its own none), not
  across sources.
- Windows are 120 s (dose-pkgc6), 60 s (sysfs-vs-bpf) and 600 s (adaptive).
